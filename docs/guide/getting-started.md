# 快速开始

欢迎使用本文档站。这是一个基于 **Docsify** 搭建的在线文档站，可以直接浏览 `docs/` 目录下的 Markdown 文件，无需任何构建步骤。

## 它能做什么

本站把 `docs/` 目录里的 `.md` 文件实时渲染成网页。你只需要往目录里丢 Markdown，刷新页面就能看到效果。

### 适用场景

- 团队内部的知识库与操作手册
- 项目的使用说明与 API 文档
- 个人笔记与技术沉淀

## 环境准备

开始之前，请确认本机已经安装了 Node.js（建议 16 及以上版本）。

### 安装与启动

推荐使用 `docsify-cli` 在本地预览。按顺序执行下面的命令：

1. 全局安装命令行工具
2. 进入项目根目录
3. 启动本地服务并在浏览器打开

```bash
# 全局安装 docsify-cli
npm install -g docsify-cli

# 进入项目目录
cd online-docs

# 启动本地预览服务（默认端口 3000）
docsify serve docs
```

启动成功后，浏览器访问 `http://localhost:3000` 即可看到文档站首页。

## 目录结构约定

本站按子目录对文档进行分类，常见约定如下：

- `guide/` —— 使用指南与入门教程
- `notes/` —— 日常笔记与零散记录
- 根目录 `_sidebar.md` —— 控制左侧导航栏的结构

> **注意**：新增文档后，记得同步更新 `_sidebar.md`，否则左侧导航里不会出现对应入口。不过直接通过 URL 仍然可以访问到文件。
