# 检测技术与分型原理

> 专题一「筛查与检测」的技术深入补充。整理自 HPV 检测方法学综述、cobas/Aptima 临床验证研究及 Meijer 验证标准等权威来源。文末附来源链接。
>
> ⚠️ 本文为文献要点摘要，仅供参考，不构成医学建议。详见 [免责声明](/hpb-docs/disclaimer.md)。

## 🗣️ 大白话速览（先看这个）

- **查 HPV 不是抽血验抗体，也不是培养病毒**，而是直接在宫颈/阴道取的样本里**找病毒的"基因"**（DNA 或 RNA）。有就是阳性，没有就是阴性。
- **怎么找到？** 病毒基因太微量，机器会用两种办法放大：要么**把病毒基因本身复印亿万份再读**（PCR 这类，最常用、最灵敏），要么**放大"找到了"的信号**（老一代的 HC2）。
- **怎么分清是几号病毒？** 给每个型号配一把"专属钥匙"（引物/探针），哪把钥匙对上了，就是哪一型。所以机器能告诉你是不是 16 号、18 号。
- **报告为什么常把 16、18 单独列、其他打包成"其他高危"？** 因为 16、18 最危险（占宫颈癌七成以上），医生看到 16/18 阳性会**直接安排进一步检查**，所以要单独拎出来；其余十几种高危型危险性相对低些，先合在一起报。
- **还有一种更"精准"的查法**：不查"病毒在不在"，而查"病毒的坏基因（E6/E7）有没有在干活（mRNA）"——干活了才更可能出事，所以**误报更少**。
- **不是随便哪个试剂都能用**：用于筛查的检测必须经过国际权威标准（Meijer 标准）验证灵敏度和稳定性达标，才允许上临床。

> 一句话：**取样 → 放大找病毒基因 → 用"专属钥匙"认出具体型号 → 把最危险的 16/18 单独报告**，而且用的试剂都得是通过权威验证的。

## 一、检测的本质：查核酸，不查抗体

临床 HPV 检测**不是验抗体、也不是做病毒培养**（HPV 无法常规体外培养，自然感染抗体又弱又晚），而是**直接检测病毒的核酸**——查标本里有没有高危型 HPV 的 **DNA** 或 **mRNA**。这是所有主流方法的共同底层逻辑。

## 二、三大技术路线（怎么"检出"）

| 路线 | 原理 | 代表 |
|---|---|---|
| **信号放大**（signal amplification） | 不增加病毒核酸本身，而是放大"检测信号"：病毒 DNA 与 RNA 探针杂交后放大信号读取 | **HC2（第二代杂交捕获）**、Cervista |
| **靶标扩增**（target amplification，DNA） | 用 PCR / 实时荧光 PCR **把病毒 DNA 本身扩增**成千上万倍再检测，灵敏度高、可定型 | **cobas、Abbott RealTime/Alinity m、BD Onclarity、Cepheid Xpert、Seegene Anyplex** |
| **mRNA 扩增** | 检测 E6/E7 **mRNA 转录本**（病毒"癌基因"是否在活跃表达），特异性更高 | **Aptima（TMA 转录介导扩增）**、PreTect Proofer（NASBA） |

> mRNA 路线的临床意义：DNA 阳性只说明"病毒在"，而 E6/E7 mRNA 阳性说明"致癌基因正在干活"，对真正有临床意义的病变**特异性更好、假阳性更少**。

## 三、查的是基因组哪一段

- **L1（主要衣壳基因）**：高度保守，很多"共识引物 PCR"用它做靶点（一网打尽各型）。
- **E6/E7（癌基因）**：既是 DNA 检测靶点，也是 mRNA 检测的唯一靶点。
- 权威对照研究显示：同等条件下，**L1 与 E6/E7 两类靶点性能基本等效**，可互换用于筛查；少数差异集中在个别型别（如 39、52、66）的检出下限上。

## 四、关键：怎么"区分型号"（genotyping 分型）

同样是查核酸，区分是 16 型还是 18 型靠三种策略：

1. **型别特异引物 + 多重/巢式 PCR**：为每个型设计专属引物，能分辨**混合感染**（一人同时感染多型）。
2. **共识 PCR + 反向点杂交 / 线性探针（line-blot）**：先用共识引物把各型都扩出来，再用一排型别特异探针"对号入座"（如 Linear Array 可分 37 型）。同时常设 **β-globin 人源基因**做质控，确认标本细胞量够。
3. **实时荧光 + 分子信标 / 不同荧光通道**：扩增同时用针对特定型别的荧光探针实时读信号——cobas 就是用**不同荧光通道**把 16、18 单独拎出来。

## 五、分型的三个"颗粒度"层级

| 层级 | 报告方式 | 代表 |
|---|---|---|
| **不分型** | 只给"14（或 13）种高危型混合阳性/阴性" | **HC2** |
| **部分分型**（主流） | **16、18 两型单独报告**，其余 12 种打包成"其他高危型阳性" | **cobas、Xpert、Onclarity 等** |
| **扩展分型** | 逐型或分组报告更多型别（16/18/31/33/45/51/52…） | Onclarity、Alinity m、Anyplex、Papilloplex 等新一代 |

**为什么单独揪出 16/18？** 这两型致癌风险最高（占宫颈癌 70% 以上）。指南（如 ASCCP）规定：**HPV16/18 阳性即使细胞学正常，也要直接转阴道镜**——分型直接决定下一步处理路径。

## 六、权威怎么认定一个检测"可用于筛查"

不是任何能测 HPV 的试剂都能用于筛查，必须通过**临床验证**：

- **Meijer 2009 标准**（国际共识，筛查用 HPV 检测的"金标尺"）：
  - 以 **HC2** 和 **GP5+/6+-PCR-EIA** 为标准对照；
  - 对 CIN2+ 的**相对灵敏度 ≥ 标准方法的 90%**、**相对特异度 ≥ 98%**；
  - **重复性**：≥500 份样本做实验室内与实验室间一致性验证。
- 目前已有 **11 种高危型 HPV DNA 检测**满足该标准（cobas、Abbott RealTime、BD Onclarity、Seegene Anyplex II、Cepheid Xpert、Hologic Aptima、PapilloCheck、Self-Screen 等），均覆盖 **14 种高危型**。
- **Aptima（mRNA）** 灵敏度略低、特异度更高，但现行验证标准本为 DNA 检测设计，对 mRNA 不完全适配。
- 新趋势：**WHO 的 HPV 目标产品档案（TPP）** 与 IPVS 指南开始要求增加**细胞量对照（cellularity control）**；扩展分型在 **VALGENT** 等框架下验证。
