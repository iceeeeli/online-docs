# 治疗与相关疾病

> 专题三。整理自 ASCCP 2019 管理共识、NCCN 宫颈癌指南（基于 FIGO 2018 分期）、CDC 2021 性传播感染治疗指南及相关权威综述。文末附来源链接。
>
> ⚠️ 本文为指南要点摘要，仅供参考，**不构成任何诊断或治疗建议**。任何治疗决策请遵从专业医生。

## 一、宫颈癌前病变的管理（ASCCP 2019）

> 以**组织学（活检确诊）**结果分级管理。

### CIN1（组织学 LSIL）
- **观察优先，不推荐治疗**：CIN1 只是活动性 HPV 感染的标志，并非癌前病变。
- **持续性 CIN1**（≥2 年连续诊断）：仍以观察为首选，治疗为可接受选项；若选择治疗且鳞柱交界与病变完全可见，切除或消融均可。

### 组织学 HSIL（CIN2 / CIN3）
- **总体原则**：需治疗时，**切除性治疗优先**（如 **LEEP 环形电切、冷刀锥切**），消融治疗为可接受替代。
- **CIN3**：所有非妊娠患者**必须治疗，观察不可接受**——CIN3 是宫颈癌的直接前驱病变。
- **CIN2**：因有自然消退可能而更灵活；对担心治疗影响未来妊娠结局者，**可接受观察**（切除性治疗有不良产科结局风险）。
- **不可接受的做法**：对组织学 HSIL，临床研究之外**局部药物、治疗性疫苗、其他生物制剂均不可接受**；**单纯为治疗 HSIL 行子宫切除不可接受**。
- **AIS（原位腺癌）**：推荐**切除**。

### 加速治疗（"see-and-treat"）
- 即刻 CIN3+ 风险 **25%–59%**：可不经活检确认直接 LEEP（加速治疗可接受）。
- 即刻 CIN3+ 风险 **≥60%**：**加速治疗优先**（如 HPV16 阳性的 HSIL 细胞学、很少/从未筛查而 HPV 阳性 HSIL 者）。

### 治疗后随访
- HSIL/CIN2/CIN3/AIS 治疗后，推荐以 **HPV 检测或联合筛查每 3 年一次、持续至少 25 年**的长期监测。

## 二、宫颈癌：分期与治疗（FIGO 2018 + NCCN）

### FIGO 2018 分期要点
- **首次纳入淋巴结状态**：淋巴结转移归为 **IIIC** 期，对预后意义重大。
- **首次允许用影像与病理辅助分期**（MRI 测量肿瘤大小、判断宫旁浸润；PET 等）。
- **IB 期细分为三档**：IB1 ≤2 cm、IB2 >2–4 cm、IB3 >4 cm。≤2 cm 预后更好、更可能适合**保育治疗**。

### 按分期的治疗原则
| 分期 | 主要治疗 |
|---|---|
| 早期（IA、IB1、部分 IB2） | **手术或放疗**；有生育需求者可行锥切或宫颈切除术（trachelectomy）等**保育方案** |
| IB3、IIA2 及以上 | **以根治性同步放化疗为首选**（优于根治性手术） |
| 局部晚期（IIB 及以上、IVA） | **同步放化疗为标准治疗**；根治性放疗由体外放疗（EBRT）+ 近距离放疗（brachytherapy）组成 |
| 新辅助化疗 | NCCN 仅推荐用于**小细胞神经内分泌癌**（国际实践有差异） |

### 预后
- FIGO 2018 分期能有效区分 IB–IVA 的 5 年总生存（OS）与无进展生存（PFS）。
- 一项 IB3/IIA2 研究中，同步放化疗组 5 年 OS 约 **91.2%**、无病生存约 **89.3%**，优于新辅助化疗+根治手术组（85.4% / 76.7%），复发率更低（9.7% vs 20.4%）。

## 三、生殖器疣（尖锐湿疣）治疗（CDC 2021）

多由**低危型 HPV6、11** 引起。按「谁来用药」和「部位」选择：

**外生殖器疣：**
- **患者自用**：咪喹莫特（imiquimod）3.75% 或 5% 乳膏；或鬼臼毒素（podofilox）0.5% 溶液/凝胶。
- **医生给药**：液氮/冷冻探头**冷冻治疗**；三氯乙酸/二氯乙酸（TCA/BCA）80–90%。

**其他部位：**
- 尿道口：冷冻 或 手术切除。
- 阴道、宫颈疣：冷冻 或 TCA/BCA 80–90%。

**用药要点：**
- 咪喹莫特 5% 每周 3 次、最长 16 周；3.75% 每晚一次、最长 8 周（用后 6–10 小时洗净）。
- 鬼臼毒素：每日 2 次 × 3 天，停 4 天为一周期，重复数周期。**旧的鬼臼树脂（podophyllin）因诱变性已不再推荐**。
- 冷冻：每 1–2 周一次，常需多次；建议上限约 4 次疗程。

**重要提示：**
- **无单一最佳疗法**，依病变大小、数量、部位个体化选择。
- **复发率高达 25%–67%**；约 1/3 可自行消退，无症状者可选择不治疗。
- **妊娠**：禁用 podophyllin；咪喹莫特、鬼臼毒素、茶多酚（sinecatechins）在孕期安全性未确立。

## 四、其他 HPV 相关癌症

HPV 约占全球 **5% 的癌症**。各部位中 HPV 归因比例（近似）：

| 部位 | HPV 归因比例 |
|---|---|
| 肛门癌 | **90%–93%** |
| 宫颈癌 | ~近 100% |
| 阴道癌 | 40%–60% |
| 外阴癌 | 40%–51% |
| 阴茎癌 | 36%–40% |
| 口咽癌 | 12%–63% |

**HPV 阳性口咽癌（预后好 → 去强化探索）：**
- 患者更年轻、合并症少、**预后显著优于 HPV 阴性**（OS 约 80%+）。
- 因预后好，学界探索**治疗去强化**（降放疗剂量、以西妥昔单抗替代铂类、诱导化疗后按反应调整、经口手术后减少辅助放疗剂量）以减少口干、吞咽困难、听力损伤等长期毒性。
- **但 NCCN 态度谨慎**：第一代随机去强化试验（RTOG 1016、De-ESCALaTE）未能证明可改变标准，**高剂量顺铂+放疗仍是 HPV 阳性口咽癌事实上的标准治疗**。NCCN 已对 HPV 阳性/阴性口咽癌采用**不同分期标准**，并以 HPV 状态分层。
- 肛门、外阴、阴道、阴茎等其他部位尚无成熟的正式去强化框架。
