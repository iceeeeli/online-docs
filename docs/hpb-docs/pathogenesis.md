# 感染与致病机制

> 专题二。整理自 IARC 专论、Cancer Science / Oncogene / CMR 等权威综述及 PATRICIA、NCI-Kaiser 等大型队列研究。文末附来源链接。
>
> ⚠️ 本文为文献要点摘要，仅供参考，不构成医学建议。

## 一、病毒学基础

- HPV 为小型双链环状 DNA 病毒，专门感染皮肤与黏膜的鳞状上皮。
- 基因组编码早期蛋白（E1、E2、E4、E5、**E6、E7**）与晚期衣壳蛋白（L1、L2）。
- **E6、E7 是主要致癌基因**，其表达受 **E2 基因产物调控**。
- **E6 蛋白**：约 150 个氨基酸的小多肽，含两个锌指结构域；是转化蛋白，可刺激 p53 降解。
- E6、E7 均为**半衰期很短（30–90 分钟）的不稳定蛋白**，由泛素—蛋白酶体系统调控。

## 二、分子致病机制：灭活两大抑癌蛋白

HPV 致癌的核心是**灭活抑癌蛋白 p53 与视网膜母细胞瘤蛋白（pRb）**。

**E6 → 降解 p53：**
- E6 作为「桥梁」，与泛素连接酶 **E6AP** 及 p53 形成三元复合物，使 p53 被泛素化并经蛋白酶体降解。
- 还有第二条途径：E6 结合 p300-p53 复合物，阻断 p300 对 p53 的乙酰化激活。
- 后果：抑制细胞周期阻滞与凋亡，导致**染色体不稳定**。E6 还干扰 Bak、FADD 等促凋亡蛋白。

**E7 → 降解 pRb：**
- E7 结合 pRb，并通过 CUL2 依赖的 E3 连接酶复合物促其蛋白酶体降解，使 **E2F 转录因子释放**、细胞周期失控进入 S 期。
- E7 还独立于 E6 干扰 p53–p21–DREAM 通路。

**病毒整合是关键恶化事件：**
- 病毒 DNA 整合进宿主基因组时常破坏 **E2 基因** → 解除对 E6/E7 的抑制 → **E6/E7 过表达**。这在浸润癌及部分高级别病变中被检出，是从感染走向癌变的重要一步。
- E6 与 E7 协同作用，使角质细胞永生化并维持癌表型。

## 三、高危型与低危型（IARC 分类）

IARC 按致癌潜能对 HPV 分组：

| 分组 | 代表型别 | 含义 |
|---|---|---|
| **Group 1（确认致癌）** | 16、18、31、33、35、39、45、51、52、56、58、59（共 12 种） | 对人类致癌 |
| Group 2A（很可能致癌） | 68 | 很可能致癌 |
| Group 2B（可能致癌） | 26、53、66 等 | 可能致癌 |
| 低危 / Group 3 | 6、11、40、42、43、44 等 | 多致良性病变（如生殖器疣） |

**关键流行病学事实：**
- **HPV16 致癌风险最高**；**HPV16 + 18 合计约占浸润性宫颈癌的 80% 以上**。
- HPV16、18 约占全球各区域约 3/4 的宫颈癌病例；HPV31、33、45、52、58 另贡献约 15–20%。
- 据此确定了优先「八型组合」（octet）：**16、18、31、33、35、45、52、58**——致癌性最强，是 HPV 筛查检测的重点目标型别。
- WHO 及中国项目均推荐检测 **14 种高危型**。

## 四、自然史：清除、持续与进展

> 宫颈癌几乎总是由**持续性致癌型 HPV 感染**所致；但绝大多数感染会自行清除。

**清除率与时间（大型队列）：**
- **PATRICIA 研究（15–25 岁年轻女性）**：HPV 感染在 12、24、36、48 个月的累计清除率分别为 **53%、79%、87%、89%**。一过性感染中位清除时间约 6.3 个月。
- **NCI-Kaiser PaP 研究（30–65 岁）**：在不发生进展的前提下，**约 80% 的感染在 3 年内不再检出**；以竞争风险看，**7 年时 92% 清除、仅 2.7% 进展**，长期持续不进展者少见（约 5.3%）。
- 清除与年龄负相关：年轻、基线病毒载量低者更易清除。

**进展风险由型别主导：**
- 以 6 个月持续感染（6MPI）计，进展为 CIN2+ 的风险比（HR）：**HPV16 ≈ 10.4、HPV33 ≈ 9.7、HPV31 ≈ 5.7、HPV45 ≈ 5.4、HPV18 ≈ 3.9**。
- **HPV16 或 HPV33 持续感染进展至 CIN3+ 的风险约高出约 25 倍**；HPV16、HPV31 最不易清除。
- 中国 18–25 岁队列：6MPI 中 **5.0% 进展为 CIN2+、9.5% 进展为 CIN1+**；从 6MPI 到 CIN2+ 平均约 **16 个月**。
- 进展风险集中在前几年：多数型别进展率在最初 3 年急剧下降，5 年后多低于 0.1%（HPV18 例外）。

**其他影响因素**：高危型共感染、既往 HPV/CIN1 病史、持续高病毒载量、吸烟、免疫抑制（如 HIV）均增加进展风险。

## 五、宿主免疫应答（为何疫苗更重要）

自然感染诱导的免疫**弱、慢、不完整**：

- **无病毒血症**：病毒颗粒从鳞状上皮表面脱落，难以进入血液/淋巴，抗原呈递弱 → 免疫启动差。
- **血清转化慢且低**：HPV16 感染后平均约 **9 个月**才血清转化；抗体滴度低，许多人甚至不血清转化。女性对 HPV16 血清转化率约 >60%，而男性仅约 4%、总体约 7.7%（HIM 研究）。即便产生抗体也会随时间衰减。
- **以细胞免疫为主**：自然免疫主要靠 T 细胞介导，仅少数人产生可测的中和抗体。
- **对再感染保护不确定**：自然感染抗体对同型再感染的保护力仍有争议，可能仅部分/短期有效。
- **与疫苗免疫对比鲜明**：预防性疫苗诱导**高滴度、持久（>10 年）的中和 IgG 抗体**，保护力远强于自然感染，这正是疫苗价值所在。

## 六、男性与口咽、肛门部位感染

- **男性总体感染率高**：全球男性任意型 HPV 约 **31%**、高危型约 **21%**；HPV16 为最常见型别。
- **口咽**：男性口咽持续感染与 HPV 相关口咽癌高发相关；口咽 HPV 患病率男性（约 10.1%）约为女性（约 3.6%）的 3 倍；**口咽癌男性发病率约为女性的 3–5 倍**。行为因素（口交、吸烟削弱黏膜免疫）推动上升。
- **肛门（尤其 MSM）**：男男性行为者肛门 HPV 患病率可达 **50%–100%**；HIV 阳性进一步显著升高清除更差。**HPV16 是肛门感染与肛门癌最主要型别**。
- 女性生殖道病毒载量更高，故男→女与女→男口腔传播存在方向性不对称。
